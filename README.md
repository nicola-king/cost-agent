## 🎯 项目简介

Cost Agent 是一个智能化的造价管理和记忆系统，集成**变更签证全流程管理**功能。

### 核心功能
| 功能模块 | 描述 | 状态 |
|---------|------|------|
| 定额管理 | 44 条定额数据查询 | ✅ |
| 造价计算 | 智能化造价计算 | ✅ |
| **变更签证** | **全流程管理 + 证据链评分** | ✅ 新增 |
| **预警看板** | **四级预警实时监控** | ✅ 新增 |
| **报表生成** | **周报/月报自动生成** | ✅ 新增 |
| **VBA 自动化** | **7 个宏功能** | ✅ 新增 |

## 🚀 快速开始

### 基础功能
```bash
# 克隆仓库
git clone https://github.com/nicola-king/cost-agent.git
cd cost-agent

# 安装依赖
pip install -r requirements.txt

# 运行测试
python3 main.py
```

### 变更签证管理（新增）
```bash
# 1. 打开 change_order/templates/变更台账总表 - 模板.csv
# 2. 按 VBA 宏导入与使用指南.md 导入宏
# 3. 5 分钟即可开始自动化办公
```
