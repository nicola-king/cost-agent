## 💰 费用组成

### 建筑安装工程费用项目组成

```
建筑安装工程费 = 分部分项工程费 + 措施项目费 + 其他项目费 + 规费 + 税金
```

#### 1. 分部分项工程费

```
分部分项工程费 = Σ(工程量 × 综合单价)

综合单价 = 人工费 + 材料费 + 机械费 + 管理费 + 利润
```

#### 2. 措施项目费

## 💵 造价计算流程

### 步骤 1: 工程量计算

```python
# 道路工程示例
length = 1000  # 米
width = 20     # 米

# 工程量
earthwork = length * width * 0.5  # 路基土石方 (m³)
pavement = length * width          # 路面工程 (㎡)
curbing = length * 2               # 路缘石 (m)
```

### 步骤 2: 定额套用

```python
# 套用定额
quota_code = "1-3"  # 路基石方
unit_price = 15900  # 元/1000m³
quantity = 10       # 10 个单位

direct_cost = unit_price * quantity  # 直接费
```

### 步骤 3: 费用计算

```python
# 费用计算
measures = direct_cost * 0.025      # 安全文明施工费
other = direct_cost * 0.02          # 其他项目费
regulation = direct_cost * 0.28     # 规费

subtotal = direct_cost + measures + other + regulation
tax = subtotal * 0.09               # 税金

total = subtotal + tax              # 总造价
```

## 🔧 使用注意事项

### 1. 定额适用条件

- 本定额适用于重庆市行政区域内的市政工程
- 适用于新建、扩建和改建工程
- 不适用于维修和养护工程

### 2. 价格调整

- 人工单价：按重庆市造价管理站发布的价格调整
- 材料价格：按当期造价信息或市场价调整
- 机械台班：燃料价格波动超过±5% 时可调整

### 3. 特殊条件

- 高原地区：按相关规定调整
- 特殊地质：按实计算
- 夜间施工：按实际发生计算
- 冬雨季施工：按实际发生计算
