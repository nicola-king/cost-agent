### 方法 2: 手动转换

#### Excel 转 Markdown
```python
import pandas as pd
from pathlib import Path

df = pd.read_excel("文件.xlsx")
md = df.to_markdown(index=False)
with open("输出.md", "w") as f:
    f.write(md)
```

#### Word 转 Markdown
```python
from docx import Document

doc = Document("文件.docx")
text = "\n".join([p.text for p in doc.paragraphs if p.text])
with open("输出.md", "w") as f:
    f.write(text)
```

#### PDF 转 Markdown
```python
import pdfplumber

with pdfplumber.open("文件.pdf") as pdf:
    text = "\n".join([page.extract_text() for page in pdf.pages])
with open("输出.md", "w") as f:
    f.write(text)
```

#### CHM 转 Markdown
```bash
# 先转换为 PDF
chm2pdf 文件.chm -o 文件.pdf
# 然后用 pdfplumber 转换
```

#### Access 转 Markdown
```python
import pyodbc
import pandas as pd

conn = pyodbc.connect(
    r'Driver={Microsoft Access Driver (*.mdb, *.accdb)};'
    r'DBQ=文件.mdb;'
)

# 读取表
df = pd.read_sql("SELECT * FROM 表名", conn)
md = df.to_markdown(index=False)
```
