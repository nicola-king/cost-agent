## 🚀 录入方法

### 方法 1: 从 Access 数据库导入

```python
import pyodbc
import pandas as pd

# 连接数据库
conn = pyodbc.connect(
    r'Driver={Microsoft Access Driver (*.mdb, *.accdb)};'
    r'DBQ=/home/nicola/下载/重庆 18 定额配套文件/重庆 2018 定额 Access/2018(不含 1819 轨道).mdb;'
)

# 读取定额表
df = pd.read_sql("SELECT * FROM 定额子目", conn)

# 转换为 Markdown
md = df.to_markdown(index=False)
with open("市政定额.md", "w", encoding="utf-8") as f:
    f.write(md)
```

### 方法 2: 从 PDF 提取

```python
import pdfplumber

with pdfplumber.open("市政定额.pdf") as pdf:
    tables = []
    for page in pdf.pages:
        table = page.extract_table()
        if table:
            tables.append(table)
```
