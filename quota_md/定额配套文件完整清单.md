### 手动转换

**Excel → Markdown**:
```python
import pandas as pd
df = pd.read_excel("文件.xlsx")
df.to_markdown("输出.md", index=False)
```

**Word → Markdown**:
```python
from docx import Document
doc = Document("文件.docx")
text = "\n".join([p.text for p in doc.paragraphs])
with open("输出.md", "w") as f:
    f.write(text)
```

**PDF → Markdown**:
```python
import pdfplumber
with pdfplumber.open("文件.pdf") as pdf:
    text = "\n".join([page.extract_text() for page in pdf.pages])
```

**CHM → Markdown**:
```bash
# 先转换为 PDF
chm2pdf 文件.chm -o 文件.pdf
# 然后用 pdfplumber 转换
```

**Access → Markdown**:
```python
import pyodbc
import pandas as pd
conn = pyodbc.connect(r'Driver={Microsoft Access Driver (*.mdb)};DBQ=文件.mdb;')
df = pd.read_sql("SELECT * FROM 表名", conn)
df.to_markdown("输出.md", index=False)
```
